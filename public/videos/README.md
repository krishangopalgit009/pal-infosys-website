# Hero video placeholder

Add the approved, optimized production MP4 here as `pal-hero.mp4`, then set
`heroVideoSource` in `src/components/sections/HeroSection.tsx` to
`/videos/pal-hero.mp4`.

Use an H.264 MP4 with no audio track where practical, provide a matching poster,
and retain the existing poster fallback for users or browsers that cannot play it.
